# ProjectFlow User Manual

## Getting Started

### Creating an Account

1. Navigate to the login page
2. Click "Sign Up" or use the signup link
3. Enter your email and password
4. Verify your email (if required)
5. Log in with your credentials

**Note:** Your account will be automatically linked to a team member record if your email matches.

## Dashboard

The dashboard provides an overview of your projects and activities.

### Key Features

- **Project Completion Overview** - Visual chart showing project status
- **Activity Trends** - Graph of recent activity
- **Project Progress Cards** - Quick view of active projects
- **Activity Log** - Recent actions and updates
- **Quick Stats** - Summary statistics

## Projects

### Viewing Projects

- Projects are displayed in a grid or list view
- Use the toggle button to switch between views
- Click "Show Archived" to view archived projects

### Creating a Project

1. Click "Create Project" button
2. Enter project name and client
3. Set due date (optional)
4. Click "Create"

**Note:** Only users with appropriate permissions can create projects.

### Editing a Project

1. Click the menu (three dots) on a project card
2. Select "Edit"
3. Update name or client
4. Click "Save"

### Archiving a Project

1. Click the menu on a project card
2. Select "Archive"
3. Confirm the action

**Note:** Archived projects are hidden by default. Use "Show Archived" to view them.

### Unarchiving a Project

1. Click "Show Archived" to view archived projects
2. Click the menu on an archived project
3. Select "Unarchive"
4. Confirm the action

### Deleting a Project

1. Click the menu on a project card
2. Select "Delete"
3. Confirm the action

**Warning:** This action cannot be undone.

## Tasks

### Viewing Tasks

- Tasks are displayed in a table with infinite scroll
- Use filters to filter by status or priority
- Use sort dropdown to sort tasks
- Click a task to view details

### Creating a Task

1. Click "Add Task" button
2. Fill in task details:
   - Title (required)
   - Project
   - Due date
   - Priority
   - Status
   - Description (optional)
3. Click "Create"

### Assigning Tasks

1. Open task details (click on task)
2. Click on "Assignee" section
3. Search and select a team member
4. Click to assign

To unassign, click "Unassign Task" in the assignment modal.

### Setting Reminders

1. Open task details
2. Click "Set Reminder" under Due Date
3. Choose reminder option:
   - 1 hour before due date
   - 1 day before due date
   - 3 days before due date
   - 1 week before due date
   - Custom date & time
4. Click "Set Reminder"

To remove a reminder, click "Remove Reminder" in the reminder modal.

### Adding Comments

1. Open task details
2. Scroll to "Activity & Comments" section
3. Type your comment in the text area
4. (Optional) Attach files by clicking "Attach file"
5. Click "Post"

### Attaching Files

1. In task comments section, click "Attach file"
2. Select one or more files
3. Files will upload automatically
4. Post your comment to attach files

**Supported file types:** Images, PDFs, text files
**Max file size:** 10MB per file

## Team

### Viewing Team Members

- Team screen shows all team members
- View member details, roles, and task statistics
- Filter and search team members

### Editing Team Members

1. Click "Edit" on a team member
2. Update name, email, or role
3. Click "Save"

**Note:** Only admins and owners can edit team members.

## Notifications

### Viewing Notifications

- Click the notification bell icon in the header
- View all notifications in the Notifications screen
- Unread notifications are highlighted

### Marking as Read

- Click on a notification to mark as read
- Or use "Mark all as read" button

## Settings

Access settings from the sidebar to:
- Update your profile
- Change preferences
- Manage account settings

## Keyboard Shortcuts

- `Esc` - Close modals
- `Enter` - Submit forms (when focused)
- `Tab` - Navigate between fields

## Tips & Best Practices

1. **Use Filters** - Filter projects and tasks to find what you need quickly
2. **Set Reminders** - Set reminders for important tasks
3. **Assign Tasks** - Assign tasks to team members for better organization
4. **Archive Completed Projects** - Keep your workspace clean by archiving finished projects
5. **Use Comments** - Add context and updates via comments
6. **Attach Files** - Share relevant documents in task comments

## Troubleshooting

### Can't see certain features?

- Check your role/permissions
- Contact your administrator

### Tasks not loading?

- Check your internet connection
- Refresh the page
- Contact support if issue persists

### File upload failed?

- Check file size (max 10MB)
- Verify file type is supported
- Try again

## Support

For help or issues:
